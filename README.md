## Visão Geral

O **Portfólio DesWeb** é uma solução *front-end* interativa projetada para apresentar o trabalho de diferentes membros de uma equipe técnica em um único local. A interface adapta seus elementos visuais e de mídia instantaneamente ao clique de um botão, proporcionando uma experiência contínua e sem necessidade de recarregamento da página (*Single Page Application concept*).

---

## Funcionalidades

- **Troca Dinâmica de Vídeos:** Alternância fluida de arquivos `.mp4` locais de apresentação de cada membro.
- **Feedbacks Visuais em Tempo Real:** Alteração automática da cor de destaque da borda e título do portfólio conforme o perfil selecionado.
- 📱 **Design Responsivo:** Layout adaptável para telas desktop, tablets e smartphones.
- ⚡ **Zero Dependências:** Aplicação leve que roda nativamente em qualquer navegador sem necessidade de bibliotecas externas.

| **HTML5** | Estruturação semântica da aplicação e integração de reprodutor de mídia |

| **JavaScript (ES6+)** | Manipulação do DOM, controle de eventos de clique e troca dinâmica de fonte das mídias |

## 📂 Estrutura do Projeto

Certifique-se de organizar os arquivos de vídeo no mesmo diretório do arquivo `index.html`:

```text
portfolio-desweb/
├── index.html        # Arquivo único contendo a estrutura HTML, estilos CSS e scripts JS
├── prototipo.mp4     # Vídeo padrão de inicialização
├── analice.mp4       # Vídeo de apresentação da Analice
├── beatriz.mp4       # Vídeo de apresentação da Beatriz
├── catarina.mp4      # Vídeo de apresentação da Catarina
├── celso.mp4         # Vídeo de apresentação do Celso
├── samuel.mp4        # Vídeo de apresentação do Samuel
└── README.md         # Documentação oficial do projeto
